## Spacing Scale

All spacing uses Tailwind v4 utility classes mapped to the 4-point base. No custom spacing tokens — uses the default Tailwind scale directly.

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px (`gap-1`, `p-1`) | Icon gaps, pill internal padding (vertical) |
| sm | 8px (`gap-2`, `p-2`) | Gap between range buttons, pill-to-pill gap in ticker row |
| md | 16px (`gap-4`, `p-4`, `px-4`) | Page side padding (mobile), sticky bar internal padding, chart container side padding |
| lg | 24px (`gap-6`, `p-6`) | Section spacing (chart → caption → table) |
| xl | 32px (`gap-8`, `px-8`) | Page side padding (desktop ≥768px, matches layout.svelte `md:px-8`) |
| 2xl | 48px (`py-12`) | Vertical page rhythm (matches layout.svelte `md:py-12`) |
| 3xl | 64px | Not used in this phase |

**Exceptions:**
- Touch targets on mobile: minimum 44×44px (`min-h-11` = 44px, already the v1 convention; apply to ticker pills, range buttons, and `<select>`).
- Sticky bar rows: 12px top/bottom padding per row (`py-3`) to keep the bar from occupying too much vertical space on mobile while meeting 44px tap targets.
- Range strip: `gap-1` (4px) between buttons; horizontal-scroll on mobile with `overflow-x-auto`.

**Source:** Inferred from `src/routes/+layout.svelte` (`px-4 py-6 md:px-8 md:py-12`), `FilterBar.svelte` (`gap-4 p-4`), and v1 `min-h-11` convention. Confirmed multiples-of-4 only.

## Typography

Four roles, two weights. Consistent with PageHeader.svelte and existing route pages.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Heading | 30px / `text-3xl` (mobile), 36px / `text-4xl` (≥768px) | 600 / `font-semibold` | 1.2 (`leading-tight`) | Page title "Explorer" in PageHeader |
| Body | 16px / `text-base` | 400 / `font-normal` | 1.5 (`leading-normal`) | Selector label text, option text in `<select>`, breakdown table cell text |
| Label | 14px / `text-sm` | 600 / `font-semibold` | 1.4 | Ticker pill labels, range button labels, `<select>` field label above the input |
| Caption | 14px / `text-sm` | 400 / `font-normal` | 1.5 | Chart caption below chart, chart legend labels, tooltip text, auto-widen note, inline validation note for custom date clamp |

**Weights used: 400 (normal) and 600 (semibold). No other weights.**

Tabular numerals (`tabular-nums` Tailwind class) on all `n=` values, fish/angler values, and date labels in the tooltip — matches PerAnglerMetric.svelte convention.

**Source:** PageHeader.svelte (`text-3xl md:text-4xl font-semibold leading-tight`), FilterBar children (`text-sm font-semibold`), trends/+page.svelte caption (`text-sm text-(--color-text-muted)`), PerAnglerMetric.svelte (`tabular-nums`).

## Component Anatomy

### 1. ExplorerHeader.svelte (NEW)

Sticky top bar. Three rows on mobile (<768px), collapses to two rows on desktop (≥768px). Sits above the `<main>` scroll area; uses `sticky top-0 z-20 bg-(--color-surface)` with a bottom border `border-b border-(--color-border)`.

**Note:** The global nav in `+layout.svelte` is `md:sticky md:top-0 md:z-10`. ExplorerHeader must use `z-20` to sit above the nav layer, and must calculate `top` relative to the nav bar height (~48px on desktop). On mobile the nav is not sticky (no `z` stacking needed); ExplorerHeader can use `top-0`.

```
<header class="sticky top-0 z-20 bg-(--color-surface) border-b border-(--color-border)">
  <div class="px-4 md:px-8">

    <!-- Row 1 (mobile): Ticker pills — always visible -->
    <div class="py-3 flex items-center gap-2">
      <TickerPills />          <!-- [Boat] [Species] [Landing] -->
    </div>

    <!-- Row 2 (mobile): Selector — always visible -->
    <div class="py-2">
      <ItemSelector />         <!-- native <select> full-width -->
    </div>

    <!-- Row 3 (mobile) / Row 2 (desktop md:flex-row): Range strip -->
    <div class="py-2 md:py-3">
      <RangeStrip />           <!-- 1M 3M 6M 1Y 2Y 5Y All Custom -->
      <!-- Custom inputs — conditionally rendered below strip -->
      {#if range === 'custom'}
        <CustomDateInputs />   <!-- From / To inputs + clamp note -->
      {/if}
    </div>

    <!-- Auto-widen note — conditionally rendered -->
    {#if autoWidened}
      <p class="py-1 text-sm text-(--color-text-subtle)">
        No 1Y data — showing full history.
      </p>
    {/if}

  </div>
</header>
```

**Desktop layout (≥768px):** Row 1 (pills) and Row 2 (selector) sit inline left; Range strip sits inline right. Achieved with `md:flex-row md:items-center md:justify-between` on the outer wrapper. The ticker pills and `<select>` occupy the left portion; the range strip occupies the right. Custom date inputs expand below the strip when active.

### 2. TickerPills.svelte (NEW)

Segmented pill toggle. Three buttons in a row.

```
<div role="group" aria-label="Ticker type" class="flex gap-2">
  <button
    role="button"
    aria-pressed={ticker === 'boat'}
    class="min-h-11 rounded-full px-4 py-2 text-sm font-semibold
           [active]: bg-(--color-accent) text-white
           [inactive]: bg-(--color-surface-muted) text-(--color-text-muted)
                       hover:bg-(--color-accent-bg) hover:text-(--color-accent)"
  >Boat</button>
  <button aria-pressed={ticker === 'species'} ...>Species</button>
  <button aria-pressed={ticker === 'landing'} ...>Landing</button>
</div>
```

States:
- **Selected:** `bg-(--color-accent) text-white` — full accent fill, white label
- **Unselected default:** `bg-(--color-surface-muted) text-(--color-text-muted)`
- **Unselected hover:** `bg-(--color-accent-bg) text-(--color-accent)` (light blue bg, accent text)
- **Focus-visible:** 2px surface offset + 4px accent ring (from `app.css` global rule)
- **Min tap target:** `min-h-11` (44px height) + sufficient horizontal padding

### 3. ItemSelector (inline in ExplorerHeader or as ItemSelector.svelte)

Native `<select>`. Full-width on mobile. Matches v1 FilterBar pattern exactly.

```
<label class="flex flex-col gap-1">
  <span class="text-sm font-semibold text-(--color-text-muted)">
    {tickerLabel}  <!-- "Boat" | "Species" | "Landing" -->
  </span>
  <select
    class="min-h-11 w-full rounded border border-(--color-border) bg-(--color-surface) px-2
           text-base focus:border-(--color-border-strong)"
  >
    {#each options as opt}
      <option value={opt.value}>{opt.label}</option>
    {/each}
  </select>
</label>
```

States:
- **Default:** `border-(--color-border) bg-(--color-surface)`
- **Focus:** system focus ring from `app.css` + `border-(--color-border-strong)` via focus class
- **Disabled:** `opacity-50 cursor-not-allowed` (e.g., if no options available; should not occur in normal flow)

**Option label format by ticker type:**
- Boat: `{display_name}` verbatim (e.g., "Pacific Voyager")
- Species: verbatim SD name (e.g., "bluefin", "dorado") — no normalization
- Landing: verbatim name (e.g., "Fisherman's Landing", "Point Loma Sportfishing")

### 4. RangeStrip.svelte (NEW)

Eight buttons in a horizontal-scrollable row. No wrapping on mobile.

```
<div class="flex gap-1 overflow-x-auto pb-1" role="group" aria-label="Time range">
  {#each ranges as r}
    <button
      aria-pressed={activeRange === r.value}
      class="min-h-11 shrink-0 rounded border px-3 py-2 text-sm font-semibold
             [active]: bg-(--color-accent) text-white border-(--color-accent)
             [inactive]: bg-(--color-surface) text-(--color-text-muted) border-(--color-border)
                         hover:bg-(--color-accent-bg) hover:text-(--color-accent)
                         hover:border-(--color-accent)"
    >
      {r.label}  <!-- 1M | 3M | 6M | 1Y | 2Y | 5Y | All | Custom -->
    </button>
  {/each}
</div>
```

States:
- **Selected:** `bg-(--color-accent) text-white border-(--color-accent)`
- **Unselected default:** `bg-(--color-surface) text-(--color-text-muted) border-(--color-border)`
- **Unselected hover:** `bg-(--color-accent-bg) text-(--color-accent) border-(--color-accent)`
- **Focus-visible:** global `app.css` ring rule
- **Custom active (dates entered):** the `Custom` button renders selected state; the preset buttons render unselected

Button labels (exact): `1M`, `3M`, `6M`, `1Y`, `2Y`, `5Y`, `All`, `Custom`

### 5. CustomDateInputs.svelte (NEW)

Revealed below the RangeStrip when `Custom` is active. Two `<input type="date">` fields.

```
<div class="mt-2 flex flex-wrap gap-3 items-end">
  <label class="flex flex-col gap-1">
    <span class="text-sm font-semibold">From</span>
    <input type="date" class="min-h-11 rounded border border-(--color-border) px-2 text-sm"
           bind:value={fromDate} required />
  </label>
  <label class="flex flex-col gap-1">
    <span class="text-sm font-semibold">To</span>
    <input type="date" class="min-h-11 rounded border border-(--color-border) px-2 text-sm"
           bind:value={toDate} required />
  </label>
  {#if clampNote}
    <p class="text-sm text-(--color-text-subtle)">{clampNote}</p>
  {/if}
</div>
```

Validation behavior: clamped dates trigger `clampNote` (e.g., "Start date adjusted to earliest available data"). Both fields required; submit fires on blur of the second field (no explicit button).

### 6. Chart container in +page.svelte

```
<section class="mt-4">
  <!-- Overflow pill for series 7+ (Svelte-side, above chart) -->
  {#if overflowCount > 0}
    <OverflowPill count={overflowCount} expanded={overflowExpanded}
                  on:toggle={toggleOverflow} />
  {/if}

  <Chart
    option={chartOption}
    height={chartHeight}   <!-- "280px" mobile, "360px" ≥768px -->
    ariaLabel={chartAriaLabel}
  />

  <!-- Caption -->
  <p class="mt-2 text-sm text-(--color-text-muted)">
    {caption}
    <!-- e.g.: "Based on 347 trips across the past year. Weekly buckets, PT." -->
  </p>
</section>
```

Chart container: full width of `<main>` (which has `px-4 md:px-8`); no additional horizontal padding inside the chart section. Chart height: `280px` on mobile (<768px), `360px` on desktop (≥768px). Pass height via a reactive derived value using `window.innerWidth` or a media-query `$effect`.

### 7. OverflowPill (inline or OverflowPill.svelte)

Handles the "+N more" collapse for series 7+ in species-ticker and landing-ticker modes.

```
<button
  class="mb-2 inline-flex items-center rounded-full px-3 py-1 text-sm
         bg-(--color-surface-sunken) text-(--color-text-subtle)
         hover:bg-(--color-lowdata-bg) border border-(--color-border)"
  aria-expanded={expanded}
  aria-controls="overflow-series-list"
>
  {expanded ? 'Show fewer' : `+${count} more`}
</button>
```

When expanded, hidden series are added to the ECharts option via `dispatchAction({type:'legendToggleSelect', name})`. The pill label toggles: collapsed = `+{N} more`, expanded = `Show fewer`.

### 8. SpeciesBreakdownTable.svelte (NEW — boat ticker only)

Rendered below the chart caption. Single column on mobile, 2-column CSS grid on ≥768px.

```
<section class="mt-6">
  <h2 class="text-base font-semibold mb-3">Species caught</h2>
  <div class="grid grid-cols-1 md:grid-cols-2 gap-2">
    {#each rows as row}
      <div class="flex justify-between rounded border border-(--color-border)
                  bg-(--color-surface-muted) px-3 py-2 text-sm">
        <span class="text-(--color-text)">{row.species}</span>
        <span class="tabular-nums text-(--color-text-muted)">{row.total.toLocaleString()} total</span>
      </div>
    {/each}
  </div>
</section>
```

Sorted by `total` catch descending. Not rendered for species or landing ticker modes.

## Accessibility Contract

### Keyboard Navigation Order (sticky bar → main content)

1. Skip-to-main link (already in `+layout.svelte`)
2. Global nav links (Home / Explorer / Picker / Trends / Compare / About)
3. **ExplorerHeader** — Tab order within sticky bar:
   a. Ticker pill: Boat
   b. Ticker pill: Species
   c. Ticker pill: Landing
   d. `<select>` (item selector)
   e. Range button: 1M
   f. Range button: 3M
   g. Range button: 6M
   h. Range button: 1Y
   i. Range button: 2Y
   j. Range button: 5Y
   k. Range button: All
   l. Range button: Custom
   m. (If Custom active) From date input
   n. (If Custom active) To date input
4. OverflowPill (if visible, positioned above chart)
5. Chart container (`role="img"` — not keyboard-interactive itself)
6. SpeciesBreakdownTable (if visible — table rows are not interactive)
7. Footer

### ARIA Attributes

| Element | ARIA |
|---------|------|
| TickerPills wrapper | `role="group" aria-label="Ticker type"` |
| Each ticker pill | `role="button" aria-pressed={boolean}` |
| RangeStrip wrapper | `role="group" aria-label="Time range"` |
| Each range button | `aria-pressed={boolean}` |
| OverflowPill | `aria-expanded={boolean} aria-controls="overflow-series-list"` |

| Custom From input | `aria-label="From date"` |
| Custom To input | `aria-label="To date"` |

**Chart aria-label format:** `"{granularity} fish per angler for {ticker selection} — {range description}"`. Use `FISH_PER_ANGLER_ARIA` constant from `src/lib/copy/metrics.ts`. Examples:
- `"Weekly fish per angler for Pacific Voyager — past year"`
- `"Monthly fish per angler for bluefin across all boats — past 2 years"`

### Focus Ring

Global rule already in `app.css`: `box-shadow: 0 0 0 2px var(--color-surface), 0 0 0 4px var(--color-accent)`. Applied to `a`, `button`, `input`, `select`, `[tabindex]` with `:focus-visible`. No additional specification needed.

### Reduced Motion

`Chart.svelte` already honors `prefers-reduced-motion` by setting `animation: false` when the media query matches. The global `app.css` `@media (prefers-reduced-motion: reduce)` rule covers all CSS transitions. No new work needed.

### Touch Targets

All interactive elements in ExplorerHeader: `min-h-11` (44px) enforced. Pill labels have sufficient horizontal padding (`px-4`) to exceed 44px width on any label. Range buttons use `px-3` which on a 3-character label ("All") produces ~48px width at 14px text.

## Copywriting Contract

### Primary CTA

No explicit submit button in this phase. Controls are self-submitting (pill tap, range button tap, `<select>` change, date input blur). The primary action is implicit: the page updates immediately on any control change.

If a future need for an explicit CTA emerges (e.g., Custom date Apply button), the label is: **"Apply dates"** (specific verb + object, not "Submit" or "Go").

### Auto-Widen Note

```
No 1Y data — showing full history.
```

**Source:** D-03 in CONTEXT.md. Exact string. Placement: inside ExplorerHeader below the range strip, `text-sm text-(--color-text-subtle)`. Not a modal, not a toast — inline, dismissible by picking a different range.

### Custom Date Clamp Note

```
{field} adjusted to {bound description}.
```

Examples:
- `"Start date adjusted to earliest available data."`
- `"End date adjusted to today."`

Rendered as `text-sm text-(--color-text-subtle)` inline below the date inputs.

### Empty State

When a ticker has no data in any range (auto-widen from D-03 exhausted):

| Element | Copy |
|---------|------|
| Heading | `No data for {ticker selection} in this range` |
| Body | `We have no records for {selection} in the selected window. Try a wider time range, or pick a different {ticker type}.` |
| CTA | Not present (no action to take other than changing controls) |

Example: `"No data for Pacific Voyager in this range. We have no records for Pacific Voyager in the selected window. Try a wider time range, or pick a different boat."`

Use existing `EmptyState.svelte` component (`heading` + `body` props). No CTA prop.

**Important:** Auto-widen (D-03) runs before the empty state. The empty state only shows when auto-widen to `All` still returns no data.

### Server Error State

When the loader returns a 500 or the ECharts dynamic import fails:

| Element | Copy |
|---------|------|
| Heading | `Something went wrong` |
| Body | `We couldn't load chart data. Try refreshing the page, or check back in a few minutes.` |

Use `EmptyState.svelte` as a fallback container in the `{#if error}` branch. Full error boundary (POL-01) is deferred to Phase 11 — Phase 6 shows a minimal inline fallback.

### Loading State

While Chart.svelte is awaiting the dynamic ECharts import, it renders: `"Loading chart…"` (already built into `Chart.svelte`). No additional copy needed. The text renders inside the chart container div at `text-sm text-(--color-text-muted)`.

### Legend Label Format

```
{series name} · n={N}
```

Examples:
- `1/2 Day AM · n=47`
- `Pacific Voyager · n=12`
- `bluefin · n=203`

`n` = total trips contributing to this series across the entire selected window. `N` is the integer count. The `·` is a centered dot (U+00B7), matching `PerAnglerMetric.svelte`'s separator convention.

### Tooltip Row Format

```
{bucket label}
━━━━━━━━━━━━━━
{series name}   {value} fish/angler   n={N}
{series name}   {value} fish/angler   n={N}
...
```

- Bucket label: date (daily: `Apr 30, 2026`), ISO week (`Week of Apr 27`), or month (`Apr 2026`)
- Value: 1 decimal if <10, integer if ≥10 (matches PerAnglerMetric formatting convention)
- Unit: `fish/angler` from `FISH_PER_ANGLER_TOOLTIP_UNIT` constant in `src/lib/copy/metrics.ts` — never inline
- `n` = per-bucket trip count for that series at that specific bucket

Use ECharts `tooltip.formatter` function. Import `FISH_PER_ANGLER_TOOLTIP_UNIT` from metrics.ts.

### Chart Caption Format

```
Based on {NNN} trips across the {range label}. {Granularity} buckets, PT.
```

Examples:
- `"Based on 347 trips across the past year. Weekly buckets, PT."`
- `"Based on 1,204 trips across all available data. Monthly buckets, PT."`
- `"Based on 28 trips from Jan 5, 2025 to Feb 18, 2025. Daily buckets, PT."`

Range labels: `past month`, `past 3 months`, `past 6 months`, `past year`, `past 2 years`, `past 5 years`, `all available data`, `{fromDate formatted} to {toDate formatted}` (for custom range).

`NNN` = total trips across all visible series in the window. Formatted with locale thousand-separator (`toLocaleString()`).

### "+N more" Pill Labels

| State | Label |
|-------|-------|
| Collapsed | `+{N} more` (e.g., `+3 more`) |
| Expanded | `Show fewer` |

`N` = number of series hidden (total series minus 6).

### Nav Label

The nav item label is `Explorer` (not "Trend Explorer" or "Chart"). Added as second item after "Home": `Home / Explorer / Picker / Trends / Compare / About`. Source: D-25 in CONTEXT.md.

### Destructive Actions

None in Phase 6. No deletions, no confirmations required.

## Responsive Breakpoints

Single breakpoint: `md:` = 768px (Tailwind default). This is the only mobile/desktop split used.

| Layout element | <768px (mobile) | ≥768px (desktop) |
|----------------|-----------------|------------------|
| ExplorerHeader rows | 3 rows stacked vertically | 2 rows: top (pills + select inline) + bottom (range strip) |
| Sticky bar `top` | `top-0` (nav not sticky) | `top-[48px]` or calculate from nav height — see note |
| Chart height | `280px` | `360px` |
