## Original Core Value (v1.0)

> Given a date (or range) and a target species, help an angler pick the charter boat with the best historical odds.

This core value was retired at v1.0 close. v2 redefines around multi-axis trend exploration.

## Dropped from Scope

The following were considered in v1 but NEVER REQUIREMENTS — preserved here as anti-pattern record per CLAUDE.md:

- Per-angler individual attribution (impossible from boat-aggregate source)
- Social feed / comments / photos
- Leaderboards / gamification
- ML-based forecast models
- Push / SMS notifications
- Mandatory account to browse
- Booking / payment integration
- Bait / tackle recommendations
- GPS catch-spot maps
- Personal catch logbook
- AI-generated reports
- "ON FIRE" hype badges
- Paywall
- Sponsored boat slots in rankings
- Fake-precision projections
- Manual scrape trigger in UI
- Non-San-Diego data

These remain anti-features in v2.
