<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Component prop input → DOM render | All Svelte template interpolation auto-escapes by default (`{value}` is HTML-safe). No `{@html}` in any Phase 2 component. |
| ECharts option config (server-built) → ECharts (client) | Filter values flow into chart titles/tooltips/aria-labels. Svelte template escaping protects DOM; ECharts internally renders to canvas, no XSS surface. |
| User-controlled URL filter values → ARIA labels / chart titles | All filter values pass through Zod validation in urlState.ts (Plan 02-01); component side just renders strings — Svelte's escape covers any residual injection. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-08 | Tampering (XSS via filter value rendered in heading/aria-label) | PageHeader, Chart aria-label, EmptyState body | mitigate | Svelte template auto-escape (`{value}`) — never use `{@html ...}` in any component. /about page uses static literals only. Acceptance criterion: `grep -r "{@html" src/lib/components` returns 0. |

PerAnglerFramingProvider enforces inline framing on first instance per page. Plan 02-07 adds grep-lint guarding `fish/angler` outside the component. |

      import { getContext } from 'svelte';

    Component 4 — src/lib/components/Chart.svelte (NEW): ECharts wrapper with dynamic import. Pattern from RESEARCH.md Pattern 6 + UI-SPEC §2 lines 365-393:

    ```svelte
    <script lang="ts">
      import { onMount } from 'svelte';
      import type { EChartsOption } from 'echarts';

      let {
        option,
        height = '320px',
        ariaLabel,
        loading = false
      }: { option: EChartsOption; height?: string; ariaLabel: string; loading?: boolean } = $props();

      let chartEl: HTMLDivElement;
      let chart: any = null;
      let mounted = $state(false);

      onMount(() => {
        let ro: ResizeObserver | null = null;
        let cancelled = false;

        (async () => {
          // Dynamic import — keeps echarts out of SSR bundle (~800kB)
          const [coreMod, chartsMod, componentsMod, renderersMod] = await Promise.all([
            import('echarts/core'),
            import('echarts/charts'),
            import('echarts/components'),
            import('echarts/renderers')
          ]);
          if (cancelled) return;
          const { use, init } = coreMod;
          const { LineChart, HeatmapChart } = chartsMod;
          const { TooltipComponent, GridComponent, VisualMapComponent, CalendarComponent, LegendComponent } = componentsMod;
          const { CanvasRenderer } = renderersMod;
          use([
            LineChart, HeatmapChart,
            TooltipComponent, GridComponent, VisualMapComponent, CalendarComponent, LegendComponent,
            CanvasRenderer
          ]);
          chart = init(chartEl);
          // Honor reduced-motion preference (UI-SPEC §Accessibility)
          const reducedMotion = typeof window !== 'undefined'
            && window.matchMedia('(prefers-reduced-motion: reduce)').matches;
          chart.setOption({ ...option, animation: !reducedMotion });
          ro = new ResizeObserver(() => chart?.resize());
          ro.observe(chartEl);
          mounted = true;
        })();

        return () => {
          cancelled = true;
          ro?.disconnect();
          chart?.dispose();
          chart = null;
        };
      });

      // Re-apply option on prop change (D-19 filter changes)
      $effect(() => {
        if (chart && option) {
          const reducedMotion = typeof window !== 'undefined'
            && window.matchMedia('(prefers-reduced-motion: reduce)').matches;
          chart.setOption({ ...option, animation: !reducedMotion }, true /* notMerge */);
        }
      });
    </script>

    <div
      bind:this={chartEl}
      role="img"
      aria-label={ariaLabel}
      style="width:100%;height:{height}"
      class="bg-[--color-surface-muted]"
    >
      {#if !mounted || loading}
        <div class="flex h-full w-full items-center justify-center text-sm text-[--color-text-muted]">
          Loading chart…
        </div>
      {/if}
    </div>
    ```

    Critical: NEVER use `import * as echarts from 'echarts'` or `import 'echarts'` at the top level. The dynamic import inside onMount is what keeps SSR fast.
