## Critical Findings

### One integration defect (in executed code)

**`src/routes/picker/+page.svelte:180` — heatmap unreachable when rankings empty.**

The picker page short-circuits to `EmptyState heading="No matching trips"` when `data.rankings.length === 0`, but this blocks the heatmap branch at line 185 from rendering even when `data.heatmap` is correctly populated with forecast-shaped stub cells. The result: when a user picks a future-dated, low-historical-data combination (the *exact* scenario Phase 3 was designed to support), the calendar heatmap they need is never rendered. Logged as Gap 2 in `.planning/phases/03-forecast-layer/03-HUMAN-UAT.md:57-63` with a proposed fix.

**Affects:** TRP-08 (PARTIAL), FCT-05 (PARTIAL), FCT-07 (PARTIAL).
